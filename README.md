# MumuStudio Pro (Winterboy Studio) - Open Source Edition

Đây là phiên bản mã nguồn mở của MumuStudio Pro (Winterboy Studio). 
Phiên bản này đã được:
- Loại bỏ hoàn toàn yêu cầu đăng nhập/tài khoản (Bypass License).
- Tích hợp giao diện Sáng (Light Theme) chủ đạo với màu xanh (Blue).
- Thêm hiệu ứng Tuyết rơi (Snow Effect) đẹp mắt có thể Bật/Tắt ngay trên thanh tiêu đề.

## Hướng dẫn cài đặt và chạy từ mã nguồn
1. Cài đặt Python 3.12+
2. Cài đặt các thư viện cần thiết:
   ```bash
   pip install customtkinter tkinter
   ```
3. Chạy phần mềm:
   ```bash
   python main.py
   ```
